3concat()拼接字符串
 > MySQL 用来**修改 XML 文档里节点内容**的函数

1. **第 1 个参数 xml_target（a）：目标 XML 文本** 原本要传一段 xml 字符串；报错注入的时候**随便填个数字 / 字符串占位就行，比如写 1**，它不参与报错核心。
2. **第 2 个参数 xpath_expr（b）：XPath 路径（最重要！注入点）** 本来写合法的 xpath 路径，用来定位 xml 里面哪个节点要修改。 👉 报错注入核心：**这里故意写非法 xpath**，MySQL 校验 xpath 格式的时候，直接把这个参数里的内容放到报错信息里弹出来！ 我们套上 `concat(0x7e,查询语句)`，`0x7e` 就是 `~`，`~` 不属于合法 xpath 字符，直接触发报错回显数据。
3. **第 3 个参数 new_xml（c）：替换成的新内容** 找到节点之后，替换成什么 xml；报错注入也是随便填个 1 占位，没用
